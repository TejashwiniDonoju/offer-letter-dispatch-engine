# 📄 Offer Letter Dispatch & Recruitment Management System

A full-stack MERN application that streamlines the offer letter dispatch process for recruiters. The application enables recruiters to securely upload candidate data, review and edit records, select email templates, and send personalized offer letters individually or in bulk using the **Brevo Email API**.

🌐 **Live Demo:** https://offer-letter-dispatch-engine.vercel.app

---

## 🚀 Features

- 🔐 JWT-based User Authentication
- 📂 Upload candidate details through CSV files
- ✏️ Review and edit uploaded candidate information
- 📧 Select and customize email templates
- 📨 Send personalized offer letters via Brevo Email API
- 🚀 Bulk email dispatch
- 📱 Responsive user interface
- 🔄 Candidate CRUD operations
- ☁️ Deployed on Vercel

---

# 📌 Application Workflow

### 🔹 Step 1: Login

Users authenticate securely using JWT authentication.

### 🔹 Step 2: Upload CSV

Recruiters upload a CSV file containing candidate information.

Example fields:

- Candidate Name
- Email
- Job Role
- Salary
- Joining Date
- Company Name

---

### 🔹 Step 3: Review & Edit

Uploaded candidate details can be:

- Modified
- Updated
- Verified

before sending emails.

---

### 🔹 Step 4: Select Email Template

Choose an email template.

The application automatically replaces placeholders with candidate-specific information.

---

### 🔹 Step 5: Send Offer Letters

Recruiters can

- Send emails individually
- Send emails in bulk

using the **Brevo Email API**.
